源全ゴシックは、全てあなたの所為です。様のMVの字幕に似せて作られたフォントです。
漢字に対し仮名が76~75％ほどに設定されています。
半角の?,!は全角の？,！よりも位置が低いです。また、仮名はプロポーショナルとなっています。
旧バージョンの源全ゴシックとは別に、１から作り直したので割と大きく違います。
旧バージョンの見た目のほうが良い方は引き続き旧バージョンをご利用ください。

源全ゴシックはSIL Open Font Licenseで配布されています。
再配布、商用利用、フォントデータの改変など、ご自由に行っていただけます。
当フォントの予約フォント名は「源全」です。改変したフォントを配布する場合はフォント名に「源全」を含むことはできません。
また、ライセンス表記、SIL Open Font Licenseの継承が必須となります。
普通に動画などに使う場合、クレジット表記などは必要ありません。（詳しくはSIL Open Font Licenseでググってください）

源全ゴシック改は、仮名部分に源石ゴシック、漢字、仮名の一部は源暎ゴシック、漢字の一部は源真ゴシックからお借りしました。
それらのフォントのベースとなったのは源ノ角ゴシックです。製作者様方に感謝します。

気になったことなどございましたら、「源全ゴシック」を内容に含めてツイートしてください。
エゴサに引っかかったら修正するかもしれません。
